    无提示词：固定排查顺序

    无提示词方法卡

    先圈空格前后，再判断本空作用。某个词出现在句中，不代表它就是本空的依据。

    名词短语前

    检查冠词、物主限定等。读整个短语，区分泛指、特指和搭配；a / an 看紧跟它的词开头发音。

    前后形成搭配

    连同前词和后面的内容一起看。介词可表示时间、来源、关系，也可能构成固定表达。

    连接两部分

    先读两边关系，再看已有标记。转折、递进、因果、让步等不能随便替换。

    引导从句：进阶

    先查从句有没有主语、谓语、宾语，再看缺少什么含义。what 可在从句中作成分；where 表示地点。

    句首只提醒检查大写，不决定填什么。无提示词还可能涉及代词、助动词和其他句型；本专题先练这几年的真题实际考点。

    本课题目出处

    题目均为2021—2024年深圳市中考英语语法填空，逐题标注原题号；2024按试卷40—43题编号，旧整理卷对应第5—8空。每题可打开免费来源页核对。

    课堂记录

    无提示词 · 常见候选词小导图

    先判空位作用，再进入分支缩小范围。这是中考常见候选词库，不是所有可能答案的穷举。今天先练真题实际涉及的冠词、介词、连接关系，再选做从句题。

    无提示词 → 看本空作用 → 选词类或结构 → 用句意与搭配验证
    ① 冠词

    读整个名词短语：泛指、特指、搭配和紧跟的读音一起看。

    a / an / the

    ② 介词

    看前词＋空格＋后面内容，判断固定搭配、时间、地点、来源等。

    in / on / at / to / of / for / from / with / by / about / as

    into / over / under / between / among / through / across

    without / during / before / after / since / until / till / against

    ③ 连接关系

    先说清前后关系，再核对完整结构；部分词也有其他词性。

    并列与转折：and / but / or / so / yet / nor

    原因、条件、让步：because / if / unless / although / though

    时间等：when / while / before / after / until / till / since / as / once

    成对结构：both … and …；not only … but also …；either … or …；neither … nor …

    ④ 从句引导词

    先查从句结构缺什么，再看要表达什么；有些词与上一支重合。

    that / what / which / who / whom / whose

    when / where / why / how / whether / if

    what 可在从句中作主语或宾语等；where 常表达地点。不能统一填 that。

    ⑤ 代词及限定词

    回前文找所指，再看主语、宾语、所属、自己、单复数等作用。

    I / me / my / mine / myself；you / your / yours / yourself / yourselves

    he / him / his / himself；she / her / hers / herself

    it / its / itself；we / us / our / ours / ourselves；they / them / their / theirs / themselves

    指示、替代：this / that / these / those / one / ones

    数量、范围等：some / any / many / much / more / most / few / little / all / both / each / every / either / neither / no

    其他常见限定与指代：other / another / others；something / anything / nothing / everything；someone / anyone / nobody / everybody

    ⑥ 其他结构中可能缺的词

    前三类都不吻合时，再扩大上下文检查。本专题不把无提示词限定成三类。

    不定式、否定与句型：to / not / never；感叹结构：what / how；存在结构：there

    程度及常见结构：so / such / too / enough / more / most / less / least / than / as

    be 与助动词：am / is / are / was / were / be / been / being；do / does / did；have / has / had

    其他常见功能副词：also / only / even / just / still / already / yet / very；常见情态词：can / could / may / might / must / should / will / would

    题目每空要求一个词。上面的成对短语是完整结构提示，实际只填原句缺的那个词。before、after、since、that、as 等可能兼有不同用法，要按本句作用判断；不能看到单词就固定归类。
