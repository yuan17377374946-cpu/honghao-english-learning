- 原题出处在每题题干下显示，含年份、考试类别与原题号；2024整理卷沿用第1—10空编号。

## 使用

静态页面，发布目录内 `index.html`、`style.css`、`data.js`、`app.js` 即可。浏览器本地保存如被禁止会显示提示；可以下载课堂记录备份。重练本题只重置当前题这一轮。

- 每个空提供本题的词形检查提示，常见错写会得到具体订正方向；判断反馈说明规则，最终拼写留给学生完成。
- 是非判断的路线记录保留实际结论，方便复述判断依据。

## 词形变形练习

独立入口 `word-forms.html`。151题：126道指定目标的基础变形、25道课堂自编句中运用，默认先做18题。包含动词、名词、形容词副词、代词、数词、词性转换六类，配53条规则。句中题先判断形式，再选规则，最后独立拼写；基础题直接练规则与拼写。

- 逐题保存本轮判断、帮助与首次拼写情况；看过答案不计独立完成。
- 典型错词有针对性提示；兼容中文撇号及多余空格。
- 完成后对比删去与新增的字母，并提供可抄到纸上的规则笔记。
- 回练题目在当前回练列表中固定，重练不会把正在做的题移出列表。
- 本页题目为词形专项自编练习，与原页的真题摘练明确区分；两个页面各自保存进度。

## 口头复习导图

入口 `word-forms-oral.html`：6个复习分支，53条规则细则，复用同一词形规则库。总节点、词类或主题、形式分支、细则问题逐层展开；只有点细则问题才显示具体规则与例子，每次只显示一个细则答案。

学生先复述规则并举例，再由老师展开核对、根据展开前的回答记录“能独立说出”或“需提示／没说全”；展开本身不增加掌握数。可遮住答案再说、全部收起并保留记录、导航下一处未核对内容、只看薄弱处或未核对处。待复习清单链接只打开路径，不显示答案。

口头核对独立保存在 `honghao-word-forms-oral-v1`，不影响书面练习成绩；重新打开默认全部收起，核对记录保留，可下载JSON备份。原语法填空页、词形练习页和做完题的小结都提供入口。
