# 语法填空 · 按路线找答案

2026-11-26 课堂练习。12道主练、6道进阶；题干摘录自已收集并对照解析的深圳中考真题与南山区、集团模拟卷。

- 原题出处在每题题干下显示，含年份、考试类别与原题号；2024整理卷沿用第1—10空编号。
- 所有判断题按当前原句单独编写。选错显示本句线索，不能自动跨步；选对由学生主动继续。
- 最后单独填写答案；多词答案检查空格、漏词与大小写。转折题同时接受 but / yet。
- 记录判断订正、求助、填写次数及查看答案；不把看答案计入首次独立答对。
- 每题原句、上下文、中文提示、词语解释与来源都可核对；省略处以省略号表示，非目标空必要时填入原解析答案。
- 总流程图和动词分支图在页面“流程地图”中；包含形容词转名词、动词转形容词、并列谓语、完整被动结构与拼写检查。
- 无第三方脚本，无远程成绩上传。进度只存在当前浏览器，可下载 JSON 记录。

## 使用

静态页面，发布目录内 `index.html`、`style.css`、`data.js`、`app.js` 即可。浏览器本地保存如被禁止会显示提示；可以下载课堂记录备份。重练本题只重置当前题这一轮。

## 学生试用后的调整（2026-11-26）

- 未完成题用中性的情境标题，答案通过后再显示考点；目录、课堂记录和打印题目都避免提前泄露题型。
- 每个空提供本题的词形检查提示，常见错写会得到具体订正方向；判断反馈说明规则，最终拼写留给学生完成。
- 是非判断的路线记录保留实际结论，方便复述判断依据。
- 手机和较窄平板的判断区保留原句与当前圈画；主动进入下一步后定位到原句和判断区。
- 需要前文才能判断的 DeepSeek 指代题默认提供必要上下文。
- 分组题数与主练、进阶一致；答对后显示三项检查和已核对数量，最后一题按钮改为查看记录。
