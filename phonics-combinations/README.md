# 宏浩自然拼读 字母组合与单词集合

53种常见拼写按不同读法分为61组，共335条分组词条，去重后310个单词。涵盖辅音组合、元音组合、r相关组合、词尾e规律、易错与不发音字母、辅音连缀。

每组提供常见英式音标、发音提示、中文词义、目标字母高亮和例词朗读。相同拼写的不同读音分别列出，例如ow、oo、ea、th、er、ew和u-e；gh的发音与不发音分开列出。辅音连缀标明保留多个声音，不把所有字母组合都当作单个音素。

可逐词显示，遮住中文或目标字母，选出最多20个不同单词作为本节词表。支持打印本节词表、导出本节词表和完整词库。选词与已复习分组保存在当前浏览器，不跨设备自动同步。

朗读播放完整例词，依赖设备提供的英语SpeechSynthesis语音，优先选择en-GB；若系统未提供英语语音，会显示提示，不会用字母名称冒充组合的纯音。音标与设备朗读口音可能有差异。
