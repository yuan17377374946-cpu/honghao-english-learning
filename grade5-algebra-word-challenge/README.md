# 字母任务岛 · 五晚数学闯关

五年级上册“用字母表示数和数量关系”情景应用练习，针对读题、列式、括号、原有量与变化量、逆运算、单位及图形边长的常见困难。

公开网页：https://yuan17377374946-cpu.github.io/honghao-english-learning/grade5-algebra-word-challenge/

## 内容

- 第1晚：校园任务站，找准比较对象和数量关系。
- 第2晚：创意小店，区分一次费用与每份费用，处理括号。
- 第3晚：科学体验馆，分清原有量、变化量和单位。
- 第4晚：倒推修复站，先建立正向关系，再逆向计算。
- 第5晚：空间设计师，看图列式并混合应用。

30个主关，每晚6关；10道选做挑战，每晚2道。每个情景包含2至3个小问，另配一份改变条件的变式用于回练。叠放、拼接、费用比较等较难关系主要放在后段或选做中。

题目均为原创编写，不标记为考试真题。情景设计参考的教研原则：真实数量关系、对比辨析、具体情景到符号再应用。参考：[武汉教育云汉阳区教研案例](https://kcsq.wuhaneduyun.cn/index.php?id=520611&r=teach/article/detail&sid=10917&taskId=)。未使用该案例的健康监测公式作为练习。

## 交互和记录

- 选择含义、判断列式、填写字母式、代入计算、排序倒推步骤。
- 数学上等价的表达式认可；采用有界符号解析与多项式交叉相乘比较，不执行用户输入，不靠少数数值抽样判等。
- 用大字号、厚底按压按钮、SVG必要条件图、折叠关系图和解答。
- 按小问核对，整题首次答案保留。答错或借助提示完成均进入待巩固，允许继续闯关。
- 独立做对原题和变式才更新为掌握；历史错题不删除。一次最多集中回练3道原题及其变式。
- localStorage保存草稿、当前任务、各晚中断任务、作答与错题。不同设备不自动同步，JSON导入导出用于迁移。导入替换已有记录。
- 无登录、第三方追踪、外部字体或构建依赖。

## 文件和验证

`dist/`为静态发布内容。`node check.cjs`运行题库结构、等价式、逆运算和错题生命周期检查。`content-audit.md`列出题目与参考答案，便于教师审核。

浏览器试做：验证列式与计算分别标记、错误后继续、刷新保留草稿、首次错误留存、原题与变式通过后掌握、面积题必要条件图。


## 2026-11-24 输入优化

每空配有独立的数字、字母、加减乘除、括号、平方按键；当前编辑的一空高亮。提供删除、清空、光标前移/后移及下一空。一对括号自动把光标放在中间。触屏默认使用页面点按输入，可切换为系统键盘；电脑实体键盘仍可直接输入。键盘操作不计为学习提示，不改变既有进度与错题记录。
