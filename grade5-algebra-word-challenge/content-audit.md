# 数学五晚闯关 · 题型改版审核

30个主关，10道选做。主关每天交替使用4种以上交互类型，不再每题都列式后代入。全部40道均有变式，其中30个主关的变式改为换情景和问法。

## 第1晚：校园任务站

### d1-1 给搬书记录贴标签

图书馆的小机器人每次搬 b 本书，连续搬了5次，每次都装满。把记录中的量认清楚。

1. 把记录卡与它的含义配起来。 参考：b = 每次搬的本数；5 = 搬书次数；5b = 一共搬的本数。

迁移情景：剧场每排有k个座位，开放4排，座位都可使用。

### d1-2 阅读积分，谁是已知量

蓝队的积分比橙队少12分。蓝队有 a 分。小乐想求橙队积分。

1. 应该选哪一张关系卡？ 参考：橙队 = a + 12。

2. 现在把条件改成“橙队有 a 分”，蓝队积分应怎样表示？ 参考：a − 12。

迁移情景：矮展架比高展架少15个，高展架有b个。

### d1-3 给式子找到书柜故事

漂流书柜原有60本书。不同记录里，a 都表示涉及的本数，各记录都保证书够借。请给三个式子找到各自适合的问题。

1. 把式子与能用它回答的问题配对。 参考：60 − a = 借出a本，现在剩多少本？；60 + a = 新添a本，现在一共多少本？；60 − 2a = 两天各借出a本，现在剩多少本？。

迁移情景：义卖摊原有80包贴纸。下列故事中的m表示卖出或补进的包数。

### d1-4 社团人数反过来问

科技社人数是绘画社的3倍。两张记录卡的字母含义不同，请分别完成。

1. 第一张：绘画社有 b 人，科技社有多少人？ 参考：3b。

2. 第二张：科技社有 n 人，绘画社有多少人？ 参考：n/3。

迁移情景：一个大盒装的徽章数是一个小袋装的4倍。第一张卡记录小袋有b枚，第二张卡记录大盒有n枚。

### d1-5 步数记录少了什么

今天比昨天多走800步，今天走了 p 步。小乐写“昨天 = 800 − p”。

1. 小乐主要错在哪里？ 参考：把较大的量与较小的量的位置弄反了。

2. 请帮他改成正确的字母式。 参考：p-800。

迁移情景：新苗比原来的小苗高6厘米。新苗高h厘米。记录员写“原来的小苗高6 − h厘米”。

### d1-6 布展物资调拨

布展柜里原有 x 卷彩带。上午领走18卷，下午又补进12卷；原有彩带足够上午领用。

1. 现在有多少卷彩带？用含 x 的式子表示。 参考：x-18+12。

2. 原有 x = 50 卷，现在有多少卷？ 参考：44卷。

迁移情景：柜里原有r个纸杯，上午取走16个，下午补进10个；纸杯足够领用。

### b1-1 两队调拨后差多少（选做）

蓝队原有 a 个展架，橙队原来比蓝队多12个。现在橙队把4个展架交给蓝队。

1. 交接后橙队有多少个展架？ 参考：a+12-4。

2. 交接后橙队比蓝队多多少个？ 参考：4个。

迁移情景：蓝队原有 a 个展架，橙队原来比蓝队多16个。现在橙队把5个展架交给蓝队。

### b1-2 同一批书两种标记（选做）

同一批书共36本。若用 a 表示借出的本数，用 b 表示剩下的本数。

1. 用含 a 的式子表示剩下的本数。 参考：36-a。

2. 用含 b 的式子表示借出的本数。 参考：36-b。

3. 如果剩下 b = 5 本，借出了多少本？ 参考：31本。

迁移情景：同一批书共48本。若用 a 表示借出的本数，用 b 表示剩下的本数。
