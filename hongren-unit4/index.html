先说变化，再打开小结

先回忆：fast、big、heavy分别怎样变化？

变化方法原形 → 比较级
直接加-er（本课例词）fast → faster
slow → slower
strong → stronger
small → smaller
符合双写条件时，双写末尾辅音字母，再加-erbig → bigger
辅音字母＋y结尾：y变i，再加-erheavy → heavier
easy → easier
happy → happier

big是重读闭音节，末尾只有一个辅音字母g，前面是单个短元音。fast和slow不符合这里的双写条件。不要把“短词”直接等同于“双写”。

以后再学的变化与最高级
变化原形 → 比较级 → 最高级
直接加-er / -estfast → faster → fastest
slow → slower → slowest
light → lighter → lightest
young → younger → youngest
以不发音的e结尾，加-r / -stnice → nicer → nicest
符合双写条件big → bigger → biggest
辅音字母＋y结尾heavy → heavier → heaviest
部分词在前面加more / mostdifficult → more difficult → most difficult
quickly → more quickly → most quickly
不规则变化（后续拓展）good → better → best

than在比较级后引出比较对象；对象也可以由上下文说明。形容词最高级前通常用the，并说明比较范围。
