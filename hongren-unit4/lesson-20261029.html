比较级 / 最高级 · 课后可复习

先比较意思，再判断形式。最高级放进本课句型时，要留意the。

规律原级 → 比较级 → 最高级
通常加-er / -estfast → faster → fastest
light → lighter → lightest
young → younger → youngest
以不发音e结尾nice → nicer → nicest
辅音字母+y，变y为iheavy → heavier → heaviest
easy → easier → easiest
重读闭音节，末尾单个辅音字母big → bigger → biggest
hot → hotter → hottest
多音节词等difficult → more difficult → most difficult
beautiful → more beautiful → most beautiful
不规则，单独记good / well → better → best
bad / badly → worse → worst
many / much → more → most
little（数量少）→ less → least
far → farther / further → farthest / furthest（距离）

规则表为辅导补充。本课课文中的重点词是fast、slow、heavy、light、big、small、old、young等。slowly、quickly是副词，要结合句子区分。
