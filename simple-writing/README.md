# 简单句写作 · 10月30日模块一

统一课堂入口：`../english-exams-2022-2026/?module=writing`。独立页面 `simple-writing/index.html`。

仅学习 Reading can help us…、We should…、Let’s… 三个句型。每个句型包含：

- 彩色词块与句子成分表、逐步扩句。
- 20个带中文的动作语块，默认选出5个基础语块，可切换全部20个。
- 点击替换并即时生成句子；can 句型可替换5种主语。
- 3道根据中文写句子、3道改错、2道词块排序，共24道练习。
- 复述小结，然后完成两句阅读好处、两句阅读方法和一句呼吁。

支持遮住英文/中文、可调字号、设备英语语音、保存句子、教师参考、草稿自动保存、老师点评、文字导出、JSON记录导入导出、打印学习单。

记录仅在当前浏览器保存，键为 `honghao-simple-writing-v1`。输入题按参考表达核对，忽略大小写及标点；其他合理表达可由老师确认。小作文只提供填写与检查清单，不自动判作文分数。60个语块用于课堂选用，不代表需要一节课全部学习。

以已整理的2026卷阅读倡议书为情境；五句段落为起步训练，不标作完整80词作文。所有语块和练习为原创教学材料。

维护：在 `source/` 下依次运行 `python3 data.py`、`python3 build.py`、`node --check dist/app.js`、`node check.cjs`，然后将 `dist/index.html` 复制到上一层 `index.html`。
