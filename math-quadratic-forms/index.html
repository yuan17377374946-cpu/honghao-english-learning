a 的两件事：方向与大小

三种形式中的 a 都有同样作用。

符号决定开口方向

a > 0：开口向上，有最低点。

a < 0：开口向下，有最高点。

绝对值决定开口大小

|a| 越大，开口越窄；|a| 越小，开口越宽。

比较 y = 2x² 与 y = ½x²；负数也比较绝对值，如 |−3| > |−1|。

负号和平方不要混

代入 x = −1 时，写成 (−1)² = 1。先算平方，再乘系数；不是把 −1² 当成 (−1)²。

顶点式：括号里面反号，外面照读

来自 PDF 第 2 页上半部分 · 读顶点与对称轴，辨析 x − h 和 x + h。

先找让括号等于 0 的 x
y = a(x − h)² + k　(a ≠ 0)
顶点(h, k)
对称轴直线 x = h
开口看 a 的符号
比背“反号”更稳的方法

令 x − h = 0，得 x = h。这时平方项为 0，y = k，所以顶点就是 (h, k)。

专门辨清这两个式子

形式顶点对称轴
y = a(x − h)² + k(h, k)x = h
y = a(x + h)² + k(−h, k)x = −h

第二行中的 h 是 x + h 里的同一个数，不要直接把它照抄成顶点横坐标。

y = −2(x + 3)² − 4

交点式：先让每个括号等于 0

来自 PDF 第 2 页下半部分 · 与 x 轴交点、对称轴与“y 相等，x 取中”。

交点是坐标，根是横坐标
y = a(x − x1)(x − x2)

a ≠ 0，且 x₁、x₂ 为实数。

与 x 轴交点(x₁, 0)、(x₂, 0)
对称轴
直线 x = x₁ + x₂2

当 x = x₁ 或 x = x₂ 时，至少一个因式为 0，因此 y = 0。

y 相等，x 取中

抛物线上两个不同的点，如果纵坐标相等，它们关于对称轴对称。

把两个横坐标相加，再除以 2，就得到对称轴的位置。

x = (x₁ + x₂) ÷ 2

这个方法不限于 x 轴上的点；只要是抛物线上两个不同且等高的点就可以。

两交点的中间，就是对称轴

两个常见错误

① x + 6 = 0 得 x = −6，不是 6。② 对称轴是直线 x = −3/2，不要写成点 (−3/2, 0)。

两个交点重合时

y = 2(x − 1)(x − 1) = 2(x − 1)²

只有一个交点 (1, 0)，也是顶点；可以看作两个相等的根。

没有实数交点时

y = 2x² + 4x + 7

与 x 轴无交点，不能写成含实数 x₁、x₂ 的交点式。

形式转换：今天先把配方走稳

PDF 原例讲一般式 → 顶点式；再用补充示例串起三种形式。

每一步都保持式子的值不变
PDF 原例 ④ · a = 1 的配方法
y = x² − 2x + 4
先找一次项系数的一半
−2 ÷ 2 = −1，(−1)² = 1

需要补 1，才能与前两项组成完全平方。

加上 1，再减去 1
y = x² − 2x + 1 − 1 + 4

加减同一个数，式子的值不变。

前三项合成完全平方
y = (x − 1)² − 1 + 4

因为 (x − 1)² = x² − 2x + 1。

合并常数，读出顶点
y = (x − 1)² + 3

顶点 (1, 3)；对称轴 x = 1；开口向上。

配方口诀要带条件

先让括号内的二次项系数变成 1，再补“一次项系数一半的平方”，最后合并常数。

如果 a ≠ 1，先提 a

补充示例 · 回到第 1 页原函数。

y = 2x² + 4x + 7
展开完整配方过程
= 2(x² + 2x) + 7
= 2[(x + 1)² − 1] + 7
= 2(x + 1)² − 2 + 7
= 2(x + 1)² + 5

括号内减 1，乘上外面的 2 后变成减 2。顶点仍为 (−1, 5)。

完整示范：同一个函数的三种写法

以下为补充示例，用来建立三种形式之间的联系。

起点与终点怎么变结果

转换时的三个检查点

① (x − 1)² = x² − 2x + 1，不能漏掉中间项。② 加多少就减多少。③ 有括号外系数时，乘法要作用到括号内每一项。

例题A · 已知顶点

顶点为 (1, −4)，经过点 (0, −3)，求解析式。

先问：已经知道哪两个数？

顶点给出 h = 1，k = −4，优先选顶点式。

先设式，不急着展开
y = a(x − 1)² − 4

现在只有 a 一个未知数。

代入点 (0, −3)
−3 = a(0 − 1)² − 4
−3 = a − 4 → a = 1
写出并核对
y = (x − 1)² − 4

代入 x = 0 得 y = −3；顶点也是 (1, −4)。展开可得 y = x² − 2x − 3。

独立练习A · 先说设式理由

顶点为 (−2, 3)，经过点 (0, 11)，求解析式。

核对答案与方法

先设：y = a(x + 2)² + 3。

代入：11 = a(0 + 2)² + 3，4a = 8，a = 2。

y = 2(x + 2)² + 3

核对：x = 0 时 y = 11；顶点 (−2, 3)。

易错：顶点横坐标是 −2，所以括号写 x + 2；(0 + 2)² = 4，不能漏平方。

知识点：根据顶点与一个点求二次函数解析式。

例题B · 已知两个交点

与 x 轴交于 (−1, 0)、(3, 0)，经过点 (0, −3)，求解析式。

先问：两个根是什么？

与 x 轴交点横坐标为 −1、3，优先选交点式。

先设式
y = a(x + 1)(x − 3)

令两个因式分别为 0，得到的根应是 −1 和 3。

代入点 (0, −3)
−3 = a(0 + 1)(0 − 3)
−3 = −3a → a = 1
写出并核对
y = (x + 1)(x − 3)

x = −1 或 3 时 y = 0；x = 0 时 y = −3。展开为 y = x² − 2x − 3。

独立练习B

与 x 轴交于 (1, 0)、(5, 0)，经过点 (0, 10)，求解析式。

核对答案与方法

先设：y = a(x − 1)(x − 5)。

代入：10 = a(−1)(−5) = 5a，a = 2。

y = 2(x − 1)(x − 5)

核对：x = 1、5 时 y = 0；x = 0 时 y = 10。

易错：两个根为 1、5，所以两个因式都写减号；(−1)(−5) = 5。

知识点：根据两个 x 轴交点与另一个点求解析式。

例题C · 已知三个点

经过点 (0, −3)、(1, −4)、(2, −3)，求解析式。

先设一般式
y = ax² + bx + c

三个点的横坐标不同，可列三个方程；最后检查 a ≠ 0。

优先代入 x = 0 的点
−3 = c → c = −3

这个点就是与 y 轴的交点。

代入另外两个点
−4 = a + b − 3 → a + b = −1 ①
−3 = 4a + 2b − 3 → 4a + 2b = 0 ②
消元求系数
① × 2：2a + 2b = −2
② − ① × 2：2a = 2
a = 1，b = −2
写出并核对三个点
y = x² − 2x − 3

三个点都满足原式，且 a = 1 ≠ 0。这与例题A、B是同一个函数。

另一种观察：点 (0, −3)、(2, −3) 等高，对称轴 x = 1，因此 (1, −4) 恰好是顶点。理解后可选更简便的方法。

独立练习C · 时间不足可作为课后题

经过点 (0, 2)、(1, 0)、(−1, 6)，求解析式。

核对答案与方法

设 y = ax² + bx + c。由 (0, 2) 得 c = 2。

a + b = −2
a − b = 4

两式相加：2a = 2，所以 a = 1；代回得 b = −3。

y = x² − 3x + 2

核对：代入 x = 0、1、−1，分别得到 y = 2、0、6。

易错：x = −1 时，x² = 1，但 bx = −b；不能把一次项也变成 +b。

知识点：一般式、坐标代入、二元一次方程组消元。

下课前口述一遍

一般式

y = ax² + bx + c

带符号读出 a、b、c；与 y 轴交点为 (0, c)。

对称轴 x = −b/(2a)，把顶点横坐标代回原式求纵坐标。

顶点式

y = a(x − h)² + k

顶点 (h, k)，对称轴 x = h。让括号等于 0，可以稳妥找到顶点横坐标。

交点式

y = a(x − x₁)(x − x₂)

与 x 轴交点 (x₁, 0)、(x₂, 0)，对称轴 x = (x₁ + x₂)/2。实数交点式要求有实数根。

三种形式共同的地方

a ≠ 0；a 的符号决定开口方向，|a| 决定开口大小。同一个函数转换形式前后，图像、顶点、对称轴与开口都不变。
