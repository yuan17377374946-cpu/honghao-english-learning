先分清：每一种形式，方便看什么？

三种形式中的 a 都不等于 0，且同一函数转换前后 a 不变。

今晚目标 · 识别 + 读出关键信息
Form 01

一般式

y = ax² + bx + c

展开后，按二次项、一次项、常数项排列。

一眼读出 a、b、c

与 y 轴交点是 (0, c)；顶点和对称轴需要计算。

Form 02

顶点式

y = a(x − h)² + k

一个含 x 的括号整体平方，外面再加 k。

一眼读出顶点 (h, k)

对称轴为直线 x = h。括号内的正负号要看清。

Form 03

交点式

y = a(x − x1)(x − x2)

两个一次因式相乘，适合看与 x 轴的交点。

一眼读出 (x₁, 0)、(x₂, 0)

对称轴为直线 x = (x₁ + x₂) ÷ 2。

先记住这一句

一般式看系数，顶点式看顶点，交点式看与 x 轴的交点。开口方向都看 a。

同一函数，换一种写法

补充示例 · 三个解析式表示右侧同一条抛物线。

y = x² − 2x − 3
y = (x − 1)² − 4
y = (x − 3)(x + 1)
图像没有变，容易读出的信息变了。

顶点 (1, −4)；对称轴 x = 1；与 x 轴交点 (−1, 0)、(3, 0)；与 y 轴交点 (0, −3)。

交点式有条件

在实数范围内，只有抛物线与 x 轴有交点时，才能写成交点式；相切时两个根相等。没有实数交点时，不能强行凑出 x₁、x₂。

一般式：先认系数，再找顶点

来自 PDF 第 1 页 · 系数、对称轴、顶点、交点、草图与 a 的作用。

原例题完整整理
y = ax² + bx + c　(a ≠ 0)
二次项 / 二次项系数ax² / a
一次项 / 一次项系数bx / b
常数项c
对称轴
直线 x = −b2a
顶点坐标
(−b2a, 4ac − b²4a)
与 y 轴交点(0, c)
降低计算负担

先用 x = −b/(2a) 求出顶点横坐标，再把这个 x 代回原式求 y，不必每次都套顶点纵坐标公式。

系数一定带上符号

补充辨析：y = −2x² − 3x + 1 中，a = −2，b = −3，c = 1。

缺少一次项时 b = 0；缺少常数项时 c = 0。

与坐标轴交点怎么求？

与 y 轴：令 x = 0，求 y。

与 x 轴：令 y = 0，解关于 x 的方程；若无实数解，则与 x 轴无交点。

PDF 原例 ①

从解析式到草图

y = 2x² + 4x + 7

先让宏浩说出 a、b、c，再逐步计算。

认出系数
a = 2，b = 4，c = 7
求对称轴
x = −4 ÷ (2 × 2) = −1

对称轴是直线 x = −1。

代回原式求顶点
y = 2 × (−1)² + 4 × (−1) + 7
= 2 − 4 + 7 = 5

顶点为 (−1, 5)。

按题意求交点

令 x = 0，得 y = 7，与 y 轴交点为 (0, 7)。

令 y = 0：2x² + 4x + 7 = 0。

Δ = 4² − 4 × 2 × 7 = −40 < 0

无实数解，因此与 x 轴无交点。

确定开口，画草图

a = 2 > 0，开口向上；描出顶点 (−1, 5) 和点 (0, 7)，补出对称点 (−2, 7)，平滑连接。

也可以直接判断：最低点的 y = 5 > 0，整条曲线都在 x 轴上方。

原例题图像

虚线是对称轴 x = −1，橙色点是顶点。

讲完后核对图像信息

顶点 (−1, 5)，与 y 轴交点 (0, 7)，开口向上，与 x 轴无交点。

a 的两件事：方向与大小

三种形式中的 a 都有同样作用。

符号决定开口方向

a > 0：开口向上，有最低点。

a < 0：开口向下，有最高点。

绝对值决定开口大小

|a| 越大，开口越窄；|a| 越小，开口越宽。

比较 y = 2x² 与 y = ½x²；负数也比较绝对值，如 |−3| > |−1|。

负号和平方不要混

代入 x = −1 时，写成 (−1)² = 1。先算平方，再乘系数；不是把 −1² 当成 (−1)²。

顶点式：括号里面反号，外面照读

来自 PDF 第 2 页上半部分 · 读顶点与对称轴，辨析 x − h 和 x + h。

先找让括号等于 0 的 x
y = a(x − h)² + k　(a ≠ 0)
顶点(h, k)
对称轴直线 x = h
开口看 a 的符号
比背“反号”更稳的方法

令 x − h = 0，得 x = h。这时平方项为 0，y = k，所以顶点就是 (h, k)。

专门辨清这两个式子

形式顶点对称轴
y = a(x − h)² + k(h, k)x = h
y = a(x + h)² + k(−h, k)x = −h

第二行中的 h 是 x + h 里的同一个数，不要直接把它照抄成顶点横坐标。

y = −2(x + 3)² − 4
补充辨析 · 顶点是什么？

x + 3 = 0，所以 x = −3。顶点为 (−3, −4)，对称轴为直线 x = −3，开口向下。

PDF 原例 ②
y = 3(x − 2)² + 5
先认顶点式结构

a = 3；括号是 x − 2；括号外是 +5。

读出顶点

令 x − 2 = 0，得 x = 2；此时 y = 5。

顶点 (2, 5)
读出对称轴
直线 x = 2

对称轴的位置与顶点的横坐标一致。

确定开口方向

a = 3 > 0，所以开口向上。最小值是 5，在 x = 2 时取得。

补充观察：最低点在 x 轴上方，因此与 x 轴无交点。

顶点式里的两个位置

顶点 (2, 5)；对称轴是经过顶点的竖直直线。

别把两个“交点”混在一起

顶点 (h, k) 通常不是与坐标轴的交点。求与 y 轴交点依然令 x = 0；求与 x 轴交点依然令 y = 0。

交点式：先让每个括号等于 0

来自 PDF 第 2 页下半部分 · 与 x 轴交点、对称轴与“y 相等，x 取中”。

交点是坐标，根是横坐标
y = a(x − x1)(x − x2)

a ≠ 0，且 x₁、x₂ 为实数。

与 x 轴交点(x₁, 0)、(x₂, 0)
对称轴
直线 x = x₁ + x₂2

当 x = x₁ 或 x = x₂ 时，至少一个因式为 0，因此 y = 0。

y 相等，x 取中

抛物线上两个不同的点，如果纵坐标相等，它们关于对称轴对称。

把两个横坐标相加，再除以 2，就得到对称轴的位置。

x = (x₁ + x₂) ÷ 2

这个方法不限于 x 轴上的点；只要是抛物线上两个不同且等高的点就可以。

补充口答 · 等高两点的横坐标为 −4、2

对称轴为 x = (−4 + 2) ÷ 2 = −1。注意：这里的两点不一定是与 x 轴的交点。

PDF 原例 ③
y = 5(x − 3)(x + 6)
令 y = 0，看两个因式
x − 3 = 0 或 x + 6 = 0
求出根，写成点的坐标
x₁ = 3，x₂ = −6

与 x 轴交点为 (3, 0)、(−6, 0)。

两个横坐标取平均数
x = 3 + (−6)2 = −32

对称轴为直线 x = −3/2。

确定开口，画草图

a = 5 > 0，开口向上；描出两个交点，再在 x = −3/2 处确定顶点位置。

补充计算：代入 x = −3/2 得 y = −405/4，顶点为 (−3/2, −405/4)。画草图时，可先标出顶点在 x 轴下方。

两交点的中间，就是对称轴

x、y 轴采用不同刻度；所有标注都对应原式的真实坐标。

两个常见错误

① x + 6 = 0 得 x = −6，不是 6。② 对称轴是直线 x = −3/2，不要写成点 (−3/2, 0)。

两个交点重合时

y = 2(x − 1)(x − 1) = 2(x − 1)²

只有一个交点 (1, 0)，也是顶点；可以看作两个相等的根。

没有实数交点时

y = 2x² + 4x + 7

与 x 轴无交点，不能写成含实数 x₁、x₂ 的交点式。

形式转换：今天先把配方走稳

PDF 原例讲一般式 → 顶点式；再用补充示例串起三种形式。

每一步都保持式子的值不变
PDF 原例 ④ · a = 1 的配方法
y = x² − 2x + 4
先找一次项系数的一半
−2 ÷ 2 = −1，(−1)² = 1

需要补 1，才能与前两项组成完全平方。

加上 1，再减去 1
y = x² − 2x + 1 − 1 + 4

加减同一个数，式子的值不变。

前三项合成完全平方
y = (x − 1)² − 1 + 4

因为 (x − 1)² = x² − 2x + 1。

合并常数，读出顶点
y = (x − 1)² + 3

顶点 (1, 3)；对称轴 x = 1；开口向上。

配方口诀要带条件

先让括号内的二次项系数变成 1，再补“一次项系数一半的平方”，最后合并常数。

如果 a ≠ 1，先提 a

补充示例 · 回到第 1 页原函数。

y = 2x² + 4x + 7
展开完整配方过程
= 2(x² + 2x) + 7
= 2[(x + 1)² − 1] + 7
= 2(x + 1)² − 2 + 7
= 2(x + 1)² + 5

括号内减 1，乘上外面的 2 后变成减 2。顶点仍为 (−1, 5)。

完整示范：同一个函数的三种写法

以下为补充示例，用来建立三种形式之间的联系。

起点与终点怎么变结果
一般式 → 顶点式x² − 2x − 3 = (x² − 2x + 1) − 1 − 3y = (x − 1)² − 4
一般式 → 交点式x² − 2x − 3 = (x − 3)(x + 1)y = (x − 3)(x + 1)
顶点式 → 一般式(x − 1)² − 4 = x² − 2x + 1 − 4y = x² − 2x − 3
交点式 → 一般式(x − 3)(x + 1) = x² + x − 3x − 3y = x² − 2x − 3
转换时的三个检查点

① (x − 1)² = x² − 2x + 1，不能漏掉中间项。② 加多少就减多少。③ 有括号外系数时，乘法要作用到括号内每一项。

下课前口述一遍

一般式

y = ax² + bx + c

带符号读出 a、b、c；与 y 轴交点为 (0, c)。

对称轴 x = −b/(2a)，把顶点横坐标代回原式求纵坐标。

顶点式

y = a(x − h)² + k

顶点 (h, k)，对称轴 x = h。让括号等于 0，可以稳妥找到顶点横坐标。

交点式

y = a(x − x₁)(x − x₂)

与 x 轴交点 (x₁, 0)、(x₂, 0)，对称轴 x = (x₁ + x₂)/2。实数交点式要求有实数根。

三种形式共同的地方

a ≠ 0；a 的符号决定开口方向，|a| 决定开口大小。同一个函数转换形式前后，图像、顶点、对称轴与开口都不变。
