01 · 课前热身

先看懂字母和等号

同一个字母代表同一个量

x 可以表示直径。1.57x 是 1.57 × x，单独的 x 就是 1 × x。加、减、除号要写出来。

先看等号两边写了什么

2 × 3 = 6 是等式。1.57x + x = 51.4 有等号，也有未知数，所以是方程。

两边做同样的运算

同时加、减或乘同一个数，两边仍相等。两边也能同时除以同一个数，除数不能是 0。

展开字母式和常用公式
2a 和 a²
2a = a + a，a² = a × a。比如 a = 3 时，一个等于 6，一个等于 9。
常用运算律
a + b = b + a，ab = ba。结合律可以重新分组，例如 (ab)c = a(bc)。乘法分配律 (a + b)x = ax + bx，反过来就能把 1.57x + x 写成 (1.57 + 1) × x。
长方形与正方形
长方形周长 2(a + b)，面积 ab。正方形周长 4a，面积 a²。
路程、速度和时间
路程 s = vt，速度 v = s ÷ t，时间 t = s ÷ v。先统一单位，再把数代入公式。
02 · 先列式

怎么列方程

一个半圆形礼饼的周长是 51.4 cm。这个礼饼的面积是多少？π 取 3.14。

第 1 步 · 设哪个量为 x

要算面积，需要知道半径。题目给的是周长，先设半圆的直径为 x cm，求出直径后再除以 2 得到半径。

第 2 步 · 用一句话写等量关系

半圆弧长 ＋ 直径 ＝ 半圆的周长

同样直径的整圆周长是 3.14 × x，半圆弧长就是 3.14 × x ÷ 2。

第 3 步 · 把数量换成数字和字母

弧长写在左边第一项，直径写在左边第二项，题目给的总周长写在右边。

3.14 × x ÷ 2 + x = 51.4
