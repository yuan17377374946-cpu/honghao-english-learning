公式板书 · 一元二次方程的求根公式与判别式

用配方法把左边凑成一个平方。下面每一步都可以单独展开。

第 1 步 · 两边除以 a，再移项

从一元二次方程开始。因为 a ≠ 0，等号两边可以同除以 a。

ax2+bx+c=0 x2+bax+ca=0

等号两边同减 c/a，把含 x 的项留在左边。

x2+bax=−ca
第 2 步 · 为什么补「一次项系数一半的平方」

先看完全平方公式。括号里加 p，展开后 x 的系数就是 2p。

(x+p)2 =x2+2px+p2

现在 x 的系数是 b/a。让 2p = b/a，就得到 p = b/(2a)。因此两边都加上 p²，左边就能合成一个平方。

x2+bax +b24a2 =−ca +b24a2
第 3 步 · 左边合成平方，右边通分

把 −c/a 的分子和分母同乘 4a，得到 −4ac/(4a²)。右边分母相同，就可以把分子相加。

(x+b2a)2 =−4ac+b24a2 =b2−4ac4a2
第 4 步 · 用判别式判断实数根的个数

把右边的分子记作 Δ = b² − 4ac。分母 4a² 一定大于 0，所以右边是正、零还是负，只看 Δ。

  • Δ > 0。平方等于正数，开方有正、负两个结果，因此有两个不同的实数根。
  • Δ = 0。平方等于 0，括号里只能是 0。求根公式中的两个结果相等，只有一个不同的根值。
  • Δ < 0。实数的平方不会是负数，因此没有实数根。
第 5 步 · 开平方，得到求根公式

当 Δ ≥ 0 时，两边开平方。因为 √(4a²) = 2|a|，所以先写成下面这个式子。

x+b2a =±Δ2|a|

右边已经同时取了正、负两种结果。若 a < 0，把分母 2|a| 改写成 2a，只会交换这两个结果。因此可写成 ±√Δ/(2a)。

两边同减 b/(2a)，右边合并成一个分式，就得到求根公式。

x=−b2a ±Δ2a =−b±Δ2a x=−b±b2−4ac2a
