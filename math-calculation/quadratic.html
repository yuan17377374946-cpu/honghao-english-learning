02 · 手动控制解题过程

看清每一步，为什么这样做

先口头说出下一步，再点击展开。

  1. 先整理有括号先展开，两边有x先移项、合并。
  2. 再化成1二次项系数先化成1。
  3. 移项常数移到右边，注意变号。
  4. 配方一次项系数除以2，再平方；左右同时加。
  5. 开方求根判断右边正负；大于0时保留±，最后代回原方程。
结果判断 · 开平方之前先判断正负

配成平方以后，会出现什么？

右边大于0
(x + 3)² = 16

两个不相等的实数根：
x = −3 ± 4。

右边等于0
(x + 2)² = 0

两个相等的实数根：
x₁ = x₂ = −2。

右边小于0
(x + 1)² = −2

实数的平方非负，
所以没有实数根。

右边大于0但不是完全平方数时，答案保留根号。例如 (x + 1)² = 3，得到 x = −1 ± √3，两个根都要保留。
