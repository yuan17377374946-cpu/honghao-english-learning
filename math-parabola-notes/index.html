01 / 建立整体认识

一条抛物线，先读哪些信息？

一般式

y = ax² + bx + c

a ≠ 0；可直接读出开口方向和纵轴交点(0，c)。

顶点式

y = a(x − h)² + k

直接读出顶点(h，k)、对称轴x = h和最值。

交点式

y = a(x − x₁)(x − x₂)

存在实数根时，可读出横轴交点(x₁，0)、(x₂，0)，重根允许重合。

为什么一般式的对称轴是x = −b/(2a)？展开完整推导

从一般式y = ax² + bx + c开始，条件是a ≠ 0。先用配方法变成顶点式，再解释为什么左右对称。

① 从二次项和一次项中提出a

y = a(x² + bax) + c

现在括号里x²的系数是1，方便使用完全平方公式。

② 加上、再减去“一次项系数一半的平方”

y = a[x² + bax + (b2a)² − (b2a)²] + c

括号里一次项系数是b/a，它的一半是b/(2a)。加减的是同一个数，整个式子的值保持不变。

③ 把前三项合成完全平方

y = a(x + b2a)² + c − b²4a

注意外面的a也要乘进去：a × [b²/(4a²)] = b²/(4a)，所以最后减去的是b²/(4a)。

④ 改写成y = a(x − h)² + k

y = a[x − (−b2a)]² + 4ac − b²4a

与顶点式对照：括号里的“x + b/(2a)”就是“x − [−b/(2a)]”。

h = −b2a，因此对称轴是x = −b2a

⑤ 为什么x = h就是对称轴？

取任意t > 0，分别在h左、右各走t个单位，横坐标就是h − t和h + t。

f(h − t) = a(−t)² + k = at² + k
f(h + t) = at² + k

两个点的纵坐标相等，横坐标到h的距离也相等，所以它们关于竖直直线x = h对称。这个结论与开口向上还是向下无关。

用一道具体题再核对
y = x² − 4x + 3 = (x − 2)² − 1

这里h = 2。x = 1和x = 3时，y都等于0；两个点分别在2的左、右各1个单位处，所以对称轴是x = 2。代公式也有−(−4)/(2 × 1) = 2。

一般式中的图像信息（a ≠ 0）
开口与宽窄a > 0向上，a < 0向下；在相同坐标刻度下，|a|越大越窄。
对称轴x = −b/(2a)
顶点(−b/(2a)，(4ac − b²)/(4a))
最值全体实数上：开口向上取最小值，开口向下取最大值，数值都是顶点纵坐标。
坐标轴交点与y轴交于(0，c)；令y = 0求与x轴的交点。
求表达式已知三个点可用一般式；已知顶点优先用顶点式；已知两个横轴交点优先用交点式。
横轴交点个数Δ = b² − 4ac：大于0有两个，等于0有一个，小于0没有。
理解a、b、c

a控制开口与宽窄；c是纵轴截距。b要结合x = −b/(2a)理解，改变b时顶点的横、纵坐标都可能变化。

先找顶点，再核对符号

表达式顶点怎样移动
y = a(x − h)²(h，0)由y = ax²向右移h（h < 0时向左移|h|）。
y = ax² + k(0，k)由y = ax²向上移k（k < 0时向下移|k|）。
y = a(x − h)² + k(h，k)左右、上下都移动；a保持不变。
一般式怎样配成顶点式？点击看完整步骤

例1：y = x² − 6x + 5

y = x² − 6x + 9 − 9 + 5
= (x − 3)² − 4

加9再减9，顶点为(3，−4)。

例2：y = −2x² + 8x − 3

y = −2(x² − 4x) − 3
= −2[(x − 2)² − 4] − 3
= −2(x − 2)² + 8 − 3
= −2(x − 2)² + 5

先提出−2，再配平方；括号里的−4乘以−2，变成+8。顶点为(2，5)。
