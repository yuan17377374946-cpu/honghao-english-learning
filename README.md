## 本地运行与云端记录

- 根目录的 [index.html](index.html) 是课程首页。各课的 HTML 和配套脚本在根目录或各专题目录，音频和图片随专题存放。
- 下载完整仓库后，可在仓库根目录运行 `python -m http.server 8000`，再在浏览器打开 `http://localhost:8000/`。需要加载题库或音频的页面适合通过 HTTP 打开。
- 接入 Supabase 时，在项目的 SQL Editor 运行 [supabase-schema.sql](supabase-schema.sql)。支持同步的页面登录后，可在设备间同步课程进度和生词。没有云端登录时，原有本地记录仍保存在当前浏览器。
