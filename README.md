# 宏浩英语课堂辅助网页

一个由教师在课堂中操作的轻量英语学习网页，首版集中处理长句理解、短文阅读、生词标记和课堂记录。

## 首版功能

- 20个长句分为4关，每关5句
- 黄色标记“有点模糊”，红色标记“不认识”
- 一键显示主语、动作、对象和补充成分
- 记录每句话的整体理解情况
- 只记录整套闯关有效用时，可暂停和归零
- 关卡星级、课堂记录、生词率与最近3次对比
- 约100词短文逐句理解提示
- 数据保存在当前浏览器，不需要学生登录

## 使用方法

直接打开 `index.html`，或通过 GitHub Pages 发布后在浏览器使用。

当前内置内容为界面演示课程，不自动计入正式学习档案。正式上课前，应根据当天已确认的词汇与句子替换课程内容。
