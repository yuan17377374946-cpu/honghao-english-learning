# 宏浩英语课堂辅助网页

一个由教师在课堂中操作的轻量英语学习网页，集中处理长句理解、单词构词规律、完形填空、生词标记和课堂记录。

## 首版功能

- 20个长句分为4关，每关5句
- 黄色标记“有点模糊”，红色标记“不认识”
- 一键显示主语、动作、对象和补充成分
- 记录每句话的整体理解情况
- 只记录整套闯关有效用时，可暂停和归零
- 关卡星级、课堂记录、生词率与最近3次对比
- 10棵可点击单词树，共41词，讲解词干、词缀和合成词
- 6道单词构词规律快速判断题
- 屠呦呦主题约150词完形填空，共10道四选一题
- 左侧文章、右侧选项，支持交卷判分和逐题解析
- 原有浏览器本地保存继续保留；登录宏浩账号后，课程进度和生词会同步到 Supabase 云端
- 阅读正文、题目和选项中点过的词会自动进入云端生词本

## 使用方法

直接打开 `index.html` 进入课程记录首页，或通过 GitHub Pages 发布后在浏览器使用。Day 10 和 Day 11 已分别保存为独立课程页面，后续新课不会覆盖旧课。

- Day 10：20个 `that` 引导的定语从句。
- Day 11：10棵单词树（含九年级第一单元词族）和一篇与第一单元主题相关的基础完形填空。
- Day 12：20个 `that` 定语从句、5组单词树和王贞仪主题阅读理解。
- Day 13：20个非限制性定语从句、10组单词树、2篇完形和2篇选择题阅读。

## 云端数据

Supabase 项目建立后，先在 SQL Editor 运行 `supabase-schema.sql`。网页右下角会出现“云端未登录”，可创建或登录宏浩的单独账号。同一账号在不同设备登录后会同步课程进度和生词记录。
