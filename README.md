# 宏浩英语课堂辅助网页

一个由教师在课堂中操作的轻量英语学习网页，集中处理长句理解、完形填空、生词标记和课堂记录。

## 首版功能

- 20个长句分为4关，每关5句
- 黄色标记“有点模糊”，红色标记“不认识”
- 一键显示主语、动作、对象和补充成分
- 记录每句话的整体理解情况
- 只记录整套闯关有效用时，可暂停和归零
- 关卡星级、课堂记录、生词率与最近3次对比
- 屠呦呦主题约150词完形填空，共10道四选一题
- 左侧文章、右侧选项，支持交卷判分和逐题解析
- 数据保存在当前浏览器，不需要学生登录

## 使用方法

直接打开 `index.html`，或通过 GitHub Pages 发布后在浏览器使用。

当前课程为 Day 10：20个 `that` 引导的定语从句，以及一篇与九年级第一单元主题相关的基础完形填空。
