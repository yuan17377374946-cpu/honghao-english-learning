# 宏浩的中考英语课堂

统一入口：https://yuan17377374946-cpu.github.io/honghao-english-learning/english-exams-2022-2026/

顶部切换三个模块：

- 中考真题：2022—2026五年、40组练习、225道客观题与5道写作题。
- 疑问句专项：60组变句例句、16组疑问词、24道听辨、12道阅读与66道专项练习。
- 自然拼读：53种常见拼写、61个发音分组，每组至少20个例词。

可直接定位到专项：`?module=questions` 或 `?module=phonics`。

专项模块首次点击时载入，切换时保留当前页面与作答状态。返回中考真题时保留原练习位置；浏览器前进/后退可切换模块。切换会停止朗读。顶部标签支持左右方向键、Home 和 End。

真题页数据与原有学习记录键保持不变。三个模块各自沿用现有浏览器记录，可在各自模块导出备份，不会自动跨设备同步。

`index.html` 内嵌全部真题、样式与切换脚本；疑问句和拼读分别复用同站 `../english-questions/` 与 `../phonics-combinations/`，独立页面仍可访问。朗读依赖设备英语语音；练习原文与专项原创内容分别标明。
